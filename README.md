# Avalanche Survivor

**A 2D survival arcade game developed using Python and Pygame.**

## About the Game

Avalanche Survivor challenges players to survive an endless barrage of falling snowballs. Players must dodge obstacles, collect special power-ups, and survive as long as possible to achieve a new high score.

## Features

- **Player Movement:** Navigate using the arrow keys.
- **Collision Detection:** Avoid falling snowballs to stay alive.
- **Time Slow Power-Up:** Temporarily reduces the speed of falling snowballs.
- **Body Heat Shield:** Provides temporary protection by melting incoming snowballs.
- **High Score System:** Tracks the player's best survival time.
- **Start and Game Over Screens:** Interactive game states with restart functionality.

## Technologies Used

- Python
- Pygame Community Edition
- Random module
- File handling for high-score storage

## How to Play

1. Launch the game.
2. Press SPACE to begin.
3. Use the LEFT and RIGHT arrow keys to dodge falling snowballs.
4. Collect power-ups to increase your chances of survival.
5. Survive as long as possible and beat your high score.

## Installation

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required dependency:

   `pip install -r requirements.txt`

5. Run the Python game file:

   `python main.py`
